# Welcome to Plain

Plain is a Markdown editor for your own writing. Your text stays a plain `.md` file on disk, and Plain styles it as you type: headings grow, emphasis turns italic, links turn blue, and the Markdown marks fade back so the words come first.

This folder is a small tour. It sits in `~/Library/Application Support/Plain/Introduction/`, so edit it freely; Plain never copies it again.

## Where to start

- Open a folder with **File › Open…** (⌘O). It shows in the Files sidebar on the left.
- Make a new file with ⌘N. It stays untitled until you save it with ⌘S.
- Jump to any file with ⌘P, to any heading with ⌘R, and to any menu command with ⇧⌘P.
- Show the preview beside your text with ⇧⌘I.

## Your files are safe

Autosave writes each file half a second after you stop typing. Plain also keeps hourly, daily and weekly backups of every file you edit; find them under **File › Backups…**.
